# Contribuindo

*English: this is a personal project and it is not accepting pull requests for now. Forks are welcome under the MIT license.*

O Tio Harness é um projeto pessoal e, por enquanto, **não aceita pull requests nem contribuições de código**: só o dono
faz push e merge. Isso pode mudar; quando mudar, este arquivo diz como.

O que dá para fazer hoje:
- **Usar e adaptar:** a licença é MIT. Faça um fork, troque os packs, escreva os seus.
- **Relatar um problema:** abra uma issue, se o repositório estiver com issues habilitadas, com a versão (`python3 bin/tioh.py packs`
  mostra a do framework), o sistema operacional e o comando que falhou. Sem prazo de resposta.
- **Não envie** briefings reais, IDs de páginas ou chaves: briefings de projetos ficam fora do Git por regra.

Se você mantém um fork e quer que ele seja listado ou comparado, abra uma issue.
